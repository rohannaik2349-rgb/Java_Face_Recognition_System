# Java_Face_Recognition_System
A java-based face recognition system that detect faces and identifies individuals by comparing facial features.

This project is a Face Recognition system developed using java. it detects human faces from images or camera feed and attempts to identify individuals by comparing facial features.

The project demonstrates the practical application of computer version and face recognition using java

Features:
1] Face detection
2] Facial feature comparision
3] Face matching and detection
4] Similarity scope display
4] Java based implimantation

TECHNOLOGIES USED:
1] Maven
2] Java
3] Computer Version Library
4] Models
      |------ 1] face_recognition_sface_2021dec_int8.onnx
      |
      ------- 2] face_recognition_sface_2021dec_int8.onnx 
           

How it Works
1] The system recives image or camera input.
2] It detects the face in the input
3] I extract or compare facial feature
4] it calculate a similarity score
5] it identifies the closest matching person based on the recognition logic
